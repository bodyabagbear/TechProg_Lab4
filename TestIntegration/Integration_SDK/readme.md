Контракт бібліотеки IntegrationLib (Варіант 1)

Опис API

Бібліотека `IntegrationLib` надає функції для чисельного інтегрування математичних функцій однієї змінної.

Бібліотека скомпільована як динамічна (.dll) з використанням C-ABI (`extern "C"`).

Версія API: 1.0

Тип зв'язування: Неявне (Implicit) та Явне (Explicit).

Загальні типи даних

Для зручності використовується вказівник на функцію:

`typedef double (\*MathFunction)(double);`


Експортовані функції

1.rectangle

Сигнатура: `extern "C" double rectangle(MathFunction f, double a, double b, int n);`

Призначення: Обчислення визначеного інтеграла методом середніх прямокутників.

Параметри:

`f` вказівник на підінтегральну функцію (не має бути nullptr).

`a` нижня межа інтегрування.

`b` верхня межа інтегрування.

`n` кількість розбиттів (має бути > 0).

Результат: Наближене значення інтеграла (double).



2.trapezoid

Сигнатура: `extern "C" double trapezoid(MathFunction f, double a, double b, int n);`

Призначення: Обчислення визначеного інтеграла методом трапецій.

Параметри: Ті самі, що і для `rectangle`.

Результат: Наближене значення інтеграла (double).



3.simpson

Сигнатура: `extern "C" double simpson(MathFunction f, double a, double b, int n);`

Призначення: Обчислення визначеного інтеграла методом парабол (Сімпсона).

Параметри: Ті самі, що і для `rectangle`.

Гранична умова: Якщо `n` непарне, бібліотека автоматично збільшує його на 1 для забезпечення парності розбиття (вимога методу Сімпсона).

Результат: Наближене значення інтеграла (double).



4.integrationError

Сигнатура: `extern "C" double integrationError(double exact, double approx);`

Призначення: Обчислення абсолютної похибки обчислень.

Параметри:

\- `exact` точне значення інтеграла.

\- `approx` наближене значення, отримане одним із методів.

Результат: Модуль різниці між точним та наближеним значенням (double).
